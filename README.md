# ecommerce_product_analytics
Комплексный анализ данных интернет-магазина с использованием Python.

## Что сделано

- Data Understanding
- Data Quality Check
- Business Metrics
- Cohort Analysis
- Delivery Performance Analysis
- Seller Performance Analysis

## Стек

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Структура проекта

notebooks/

01 — Data Understanding

02 — Data Quality

03 — Business Overview

04 — Cohort Analysis

05 — Delivery Performance

06 — Seller Performance

## Основные результаты

- Исследованы ключевые бизнес-метрики
- Выполнен когортный анализ клиентов
- Проанализировано качество доставки
- Оценена эффективность продавцов
